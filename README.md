## 🚀 Open Source

### [pop](https://github.com/Arshdelight/pop)

**POP (Protocol of Practice)** — a protocol that writes practice knowledge as open data: publishable, linkable, verifiable, composable. Designed for LLM-powered automatic summarization. TypeScript CLI, ships with a full test suite.

### [loop](https://github.com/Arshdelight/loop)

AI agent orchestration + tool rendering built on Vercel AI SDK. Published on npm as [@arshdelight/loop-core](https://www.npmjs.com/package/@arshdelight/loop-core) and [@arshdelight/loop-react](https://www.npmjs.com/package/@arshdelight/loop-react).

### [create-arsh-electron](https://github.com/Arshdelight/create-arsh-electron)

One-command scaffolding for an Electron + React + TypeScript desktop app, with the boring parts (build, packaging, mirrors) pre-configured.
